# 星际2天梯直播助手

一个运行在本机的星际争霸 II 直播工具。直播姬和 OBS 都可以通过浏览器来源载入透明蒙版。普通用户下载 Windows 分享包即可使用，无需安装 Node.js、Python 或 Codex。

[下载分享包](https://github.com/icarus126c/sc2-ladder-live-assistant/releases/latest) · [赞助支持](SPONSOR.md)

## 普通用户：三步开始

1. 下载 Release 中的 Windows x64 分享包，完整解压，双击 `启动天梯助手.cmd`。
2. 在直播姬选择“添加素材 / 来源 → 浏览器”，或在 OBS 添加浏览器来源。
3. 输入 `http://127.0.0.1:17864/output`，设置 1920 × 1080，放在游戏捕获上方。

主界面为“直播预览”。上方具体场景按钮进入手动模式，“自动切换”按钮随时恢复自动判断；下方场景效果栏只做预览。空白场景隐藏全部工具图层，后台录像统计继续运行。自定义场景在“画面自定义 → 自定义场景”独立编辑，可设置图片、视频、透明背景、文字和显示工具；预览应用后生效。

控制页面会持续监听本机助手状态。连接中断或助手重启后，页面会自动重连并恢复操作，无需手动刷新；连接恢复期间会显示提示并暂停控制操作。服务关闭期间无法读取新状态，重新启动后继续监控。发送后结果不明的补记等操作不会自动重发，请先核对战绩。

## 本次直播与异常处理

主界面顶部以一行显示本场战绩与“恢复上一场”。接入说明默认折叠；“场次与诊断”收纳今日战绩和不常用操作。“开始新一场”重置本场时间范围，保留历史；“结束本场”停止计入结束之后的对局，今日累计继续更新。默认每次启动新开一场；上次未结束时可点击“恢复上一场”。战绩计分器里的记录范围可切换本次直播、今日和历史，始终只显示当前身份的记录。

点“一键诊断”检查游戏连接、身份与录像目录是否对应、自动读取开关、待关联录像及 MMR。MMR 缺失不代表录像目录一定错误；录像没有有效 MMR 时会保留原值。录像详情区分别显示已计入、已处理、未计入、待关联和解析失败。

“连接、录像与数据恢复”可备份当前数据，备份保存到 `.ladder-data/backups`。运行时会保留最近的有效数据备份；启动时遇到损坏文件会尝试自动恢复，并保留 `.corrupt-*` 原文件。没有有效备份时使用默认设置并明确提示，不会伪造丢失的记录。手动备份仅复制数据文件，恢复到另一台电脑时仍需保留自己的图片、视频和已安装风格素材目录。不要把私人数据目录加入开源仓库或分享包。

## 能做什么

- 游戏、比赛载入、等待、暂离、空白、自定义六个场景；默认开启极速自动切换，可调延迟；录像回放默认跟随比赛 / 实时观战进入游戏画面，退出回等待，可在切换调试中关闭。
- “画面自定义”集中编辑每个场景的内容、文字、媒体和布局，预览草稿应用后生效。
- 选择预览里的蓝框可以拖动按键助手、计分器、今日数据和场景文字；工具位置在各场景共用，显示内容独立。
- 本次直播胜负：从本次启动开始，默认只自动计真人 1v1，可选择计入人机 1v1；重启默认开启新一场，可选择继续上一场，跨零点不中断。
- 今日数据：按账号与北京时间当天累计自己的跳虫 / 狂热者生产、击杀敌方农民、最长对局等。
- 等待和暂离画面：独立文字、主题、图片 / 视频，以及默认关闭的可选今日数据。
- 七套内置外观、一键换装、自定义套装组合保存和外部风格包安装。
- 可关闭的按键助手：可在“小助手 → 按键助手 → 按键响应”开启全局响应，默认仅星际2前台响应；聊天保护只作用于星际2，按键不保存。默认侧后方单键盘，另可选择纯平面无角色键盘、左右半键盘及分离视角。Q 版大主教支持“集结部队”漫画差分，纳西妲与薇斯纳支持眨眼比心差分，可录制单键或组合键触发。
- 五款资源图标模板，数字镂空；原神菜单三图标和独立派蒙，红色感叹号分别开关。
- B 站礼物显示、收益记录与免费弹幕口令抽奖；官方连接所需的身份码与密钥只在本机输入。

## 录像统计设置

进入“录像与账号”，点击“自动读取本机账号”。账号列表会显示“游戏昵称 · 区服 · 完整 ID · 最近录像时间”，方便辨认；昵称来自最近可读取且完整 ID 匹配的录像，缺少可用录像时显示“昵称未读取”。一个账号会自动填入；多个账号请选择自己的账号，点击“保存身份与录像目录”，再扫描录像。工具从本机账号文件夹读取完整 ID，并从最近录像中核对昵称，不猜测当前登录账号。也可以手动填写完整 ID / 精确昵称和自己的 Multiplayer 目录。

显示昵称不用于识别自己。单位生产统计包含后来阵亡的已生产单位；手动补记但未关联录像没有单位统计。人机 1v1 可在战绩计分器开启“计入人机对局”，默认关闭；关闭后已读记录保留但不参与统计，人机不更新 MMR。旁观、身份不明和非 1v1 不自动计入。旧录像可以补齐今日数据，但不增加本次启动后的胜负。

对手选择随机时，种族胜负按录像里的实际分配种族统计。例如随机到神族，计入 vP；录像缺少分配字段时使用实际种族详情，无法确认时不猜测。重新扫描今日或最近30盘会补齐扫描范围内旧记录的种族标签，不重复增加总胜负，也保留手动修改和排除状态。

自动扫描同时覆盖今天和本次直播期间的录像，跨北京时间零点也会补记刚结束但延后保存的对局；“扫描今日”仍只更新当天范围。

在“等待画面 / 暂离画面 → 可选今日数据”勾选需要展示的项目，再点击应用；这些选项默认关闭。

今日刷叉、造狗、击杀农民等在对局结束、录像保存后自动更新；开启总开关与“自动读取1v1录像”并配置正确身份和目录即可，后台每4秒检查。直播画面的显示开关不影响后台统计。这些数值来自录像，游戏进行中不逐秒刷新；“扫描今日”用于补读或核对，平时不需要每盘手动点击。

单位跟踪统计支持原生协议及已验证的 97579、98370 兼容解码；98370 使用随项目打包的暴雪官方 98310 跟踪定义。未知版本仍显示缺失数据，不将错误数据当成零，也不使用兼容定义解析未知的位打包事件。

计分器可分别调整底色与边框、整体透明度，支持“只留文字”。“画面自定义”集中调整各小工具透明度，数值越低越透明，预览后应用生效。

## 场景编辑

左侧“画面自定义”选择游戏、载入、等待、暂离或空白。勾选图层、调整文字和主题，上传媒体，选择需要拖动的元素，再点击应用。蓝框和透明底纹只在编辑预览显示。切到另一场景前，请应用或放弃当前草稿。

编辑不会切换实际直播；实际切换到“直播预览”操作。手动切换会暂停自动模式，点击同栏的“自动切换”继续。自动模式先读取客户端界面状态；确认大厅后零额外延迟显示等待画面，开始比赛仍经两次确认。离开延迟可在主界面调试中设置。

“星灵 · 大主教与狂热者”为同一套主题，游戏控制台有两种装甲变化。丰富装饰填充空闲面板并替换肖像，保留参考星灵单单位界面的血量、攻防、小地图、技能、菜单与编队栏；仅边沿完整保留单位信息区和头像。保护镂空固定在画面坐标，装饰移动缩放不会盖入保护区。多单位选择或不同 HUD 比例请先核对预览，必要时切回仅边沿。等待、载入、暂离、计分器与 Q 版大主教助手统一风格。用法与生成提示词见 [制作记录](docs/artanis-menu-design.md)。

## 换装与混搭

在“小助手 → 按键助手”选择纳西妲或薇斯纳后，找到“可爱表情差分”，点击“录制组合键”，按住自己的组合键（例如 Ctrl + Shift + 1）后松开。可修改默认的 ♥ 对话文字、对话框开关和松开后停留时间，再点击“应用按键助手设置”。触发键默认未绑定，“演示可爱表情”只影响预览。关闭对话框仍会触发表情；纯平面键盘不显示角色。组合键区分左右修饰键。素材制作提示词见 [表情差分制作记录](docs/character-emote-prompts.md)。

选套装、选择一起更换的元素、预览三种场景，再点击应用。默认同步更换等待、载入和暂离背景；需要沿用自己的视频或图片时才勾选保留媒体。

也可以分别调整边框、助手、等待和暂离主题并应用，然后在一键换装页面“保存当前搭配”。同名保存更新原搭配；只保存外观，不保存账号、战绩、位置或私人文字。

## 从源码运行（开发者）

需要 Windows、Node.js 24+ 和 Python 3.12+。按键捕获为 Windows 功能；日常统计和本地网页逻辑没有 npm 依赖。

```powershell
python -m pip install -r requirements.txt
npm start
```

默认使用自带 Python（如有 `runtime/python/python.exe`），否则使用系统 Python；可通过 `SC2_PYTHON` 指定解释器。运行时的数据存放在 `.ladder-data`，不应提交到 Git。

```powershell
npm test
```

源码自动检查使用 Windows 的 Node.js / Python 环境。制作便携包需要已经准备好的运行目录，详见 `scripts/package.ps1`。

测试包含 `ladder-test/fixtures/` 中的公开真实录像，需要先安装上述 Python 依赖；缺少样本或依赖会报错。样本来源、校验值和许可见该目录的 README。
