# 星际2天梯直播助手

一个运行在本机的星际争霸 II 直播工具。直播姬和 OBS 都可以通过浏览器来源载入透明蒙版。普通用户下载 Windows 分享包即可使用，无需安装 Node.js、Python 或 Codex。

[下载分享包](https://github.com/icarus126c/sc2-ladder-live-assistant/releases/latest) · [赞助支持](SPONSOR.md)

## 普通用户：三步开始

1. 下载 Release 中的 Windows x64 分享包，完整解压，双击 `启动天梯助手.cmd`。
2. 在直播姬选择“添加素材 / 来源 → 浏览器”，或在 OBS 添加浏览器来源。
3. 输入 `http://127.0.0.1:17864/output`，设置 1920 × 1080，放在游戏捕获上方。

主界面为“直播预览”。上方切换会真正改变直播画面；下方场景效果栏只做预览。空白场景隐藏全部工具图层，后台录像统计继续运行。

控制页面会持续监听本机助手状态。连接中断或助手重启后，页面会自动重连并恢复操作，无需手动刷新；连接恢复期间会显示提示并暂停控制操作。服务关闭期间无法读取新状态，重新启动后继续监控。发送后结果不明的补记等操作不会自动重发，请先核对战绩。

## 能做什么

- 游戏、比赛载入、等待、暂离、空白五个场景；默认开启极速自动切换，可调延迟。
- “画面自定义”集中编辑每个场景的内容、文字、媒体和布局，预览草稿应用后生效。
- 选择预览里的蓝框可以拖动按键助手、计分器、今日数据和场景文字；工具位置在各场景共用，显示内容独立。
- 本次直播胜负：从本次启动开始，默认只自动计真人 1v1，可选择计入人机 1v1；重启开启新一场，跨零点不中断。
- 今日数据：按账号与北京时间当天累计自己的跳虫 / 狂热者生产、击杀敌方农民、最长对局等。
- 等待和暂离画面：独立文字、主题、图片 / 视频，以及默认关闭的可选今日数据。
- 六套内置外观、一键换装、自定义套装组合保存和外部风格包安装。
- 可关闭的按键助手：纯平面无角色键盘、左右半键盘、侧后方及分离视角。
- B 站礼物显示、收益记录与免费弹幕口令抽奖；官方连接所需的身份码与密钥只在本机输入。

## 录像统计设置

进入“录像与账号”，点击“自动读取本机账号”。一个账号会自动填入；多个账号请选择自己的账号，点击“保存身份与录像目录”，再扫描录像。工具从本机账号文件夹读取完整 ID，并从最近录像中核对昵称，不猜测当前登录账号。也可以手动填写完整 ID / 精确昵称和自己的 Multiplayer 目录。

显示昵称不用于识别自己。单位生产统计包含后来阵亡的已生产单位；手动补记但未关联录像没有单位统计。人机 1v1 可在战绩计分器开启“计入人机对局”，默认关闭；关闭后已读记录保留但不参与统计，人机不更新 MMR。旁观、身份不明和非 1v1 不自动计入。旧录像可以补齐今日数据，但不增加本次启动后的胜负。

自动扫描同时覆盖今天和本次直播期间的录像，跨北京时间零点也会补记刚结束但延后保存的对局；“扫描今日”仍只更新当天范围。

在“等待画面 / 暂离画面 → 可选今日数据”勾选需要展示的项目，再点击应用；这些选项默认关闭。

计分器可分别调整底色与边框、整体透明度，支持“只留文字”。“画面自定义”集中调整各小工具透明度，数值越低越透明，预览后应用生效。

## 场景编辑

左侧“画面自定义”选择游戏、载入、等待、暂离或空白。勾选图层、调整文字和主题，上传媒体，选择需要拖动的元素，再点击应用。蓝框和透明底纹只在编辑预览显示。切到另一场景前，请应用或放弃当前草稿。

编辑不会切换实际直播；实际切换到“直播预览”操作。手动切换会暂停自动模式，点击“恢复自动切换”继续。自动模式先读取客户端界面状态；确认大厅后零额外延迟显示等待画面，开始比赛仍经两次确认。离开延迟可在主界面调试中设置。

## 换装与混搭

选套装、选择一起更换的元素、预览三种场景，再点击应用。默认同步更换等待、载入和暂离背景；需要沿用自己的视频或图片时才勾选保留媒体。

也可以分别调整边框、助手、等待和暂离主题并应用，然后在一键换装页面“保存当前搭配”。同名保存更新原搭配；只保存外观，不保存账号、战绩、位置或私人文字。

## 从源码运行（开发者）

需要 Windows、Node.js 24+ 和 Python 3.12+。按键捕获为 Windows 功能；日常统计和本地网页逻辑没有 npm 依赖。

```powershell
python -m pip install -r requirements.txt
npm start
```

默认使用自带 Python（如有 `runtime/python/python.exe`），否则使用系统 Python；可通过 `SC2_PYTHON` 指定解释器。运行时的数据存放在 `.ladder-data`，不应提交到 Git。

```powershell
npm test
```

源码自动检查使用 Windows 的 Node.js / Python 环境。制作便携包需要已经准备好的运行目录，详见 `scripts/package.ps1`。

测试包含 `ladder-test/fixtures/` 中的公开真实录像，需要先安装上述 Python 依赖；缺少样本或依赖会报错。样本来源、校验值和许可见该目录的 README。

## 数据与公开版

服务只监听本机，不把录像、按键、身份码或密钥发送到项目作者。B 站连接按选择的平台方式与 B 站服务通信；OBS WebSocket 只连接本机。

软件内的赞助页默认使用占位图片，合作邮箱保持未配置。仓库首页提供[赞助说明](SPONSOR.md)入口。请勿提交自己的私人付款信息、录像、账号状态或密钥。
