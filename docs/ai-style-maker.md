# AI 主题素材制作

在“一键换装 → 制作自己的风格包”中填写基础风格、配色，再展开“AI 生成主题素材”。每次选择一种素材，输入主题与角色描述，配置图像 API，点击“按模板生成一张”。生成结果先显示为候选图；点击“采用这张素材”后才加入下面的风格包素材。

可以反复生成不同部分，也可以混用手动上传的 PNG。没有新素材的部分沿用基础风格。满意后点击“制作并安装”，在游戏／等待／暂离预览中检查，再点击“应用这套风格”。采用、安装均不会直接改变直播输出。风格包只包含名称、配色、模板和图片，可下载为 `.sc2style.json` 分享。

## 图像接口配置

支持兼容 OpenAI 格式的两种协议，地址可填写 API 根路径（如 `https://your-provider.example/v1`）或完整生成端点：

| 类型 | 模型填写方式 | 图片返回格式 |
| --- | --- | --- |
| Images | “图片模型”填写服务商支持的图片模型，例如 `gpt-image-2` | `data[0].b64_json` 或 `data[0].url` |
| Responses | “对话模型”填写能调用图片工具的主模型；“图片工具模型”填写图片模型 | `output[].type = image_generation_call` 的 `result` Base64 |

Images 默认调用 `/images/generations`；选入角色参考图或勾选发送布局参考图时，改用 `/images/edits` 的 multipart 请求，服务商必须支持图片编辑。Responses 使用 `/responses` 和 `image_generation` 工具，并发送 `store: false`。

使用 sub2api 等网关时，需要在账号／渠道配置中启用图片工具，在分组中允许生图，并把所选图片模型加入白名单。助手不读取 Codex 的配置或认证文件，用户在页面中填写自己的 API 地址和密钥。模型是否可用、计费和素材生成质量由服务商决定。

API Key 仅存在当前页面及本次服务端请求的内存里，不写入设置、日志、状态事件流或导出的风格包。刷新页面后需重新填写。向配置的接口发送的内容为主题描述、四个配色、该素材模板、可选布局图和所选角色参考图，不包含战绩、录像目录或直播账号。

常规接口使用 HTTPS，本机网关允许 localhost / 127.0.0.1 / ::1 的 HTTP。图片请求禁止重定向，下载返回图片链接时不携带 API Key。每次点击仅请求一张；同一请求标识的近期重发共用结果。网络失败、接口报错或超时不会自动再次生图。取消会停止等待并中止本机请求，但服务商可能已经处理或计费。

## 模板与适配

“查看本次模板提示词”展示实际发送的模板，并可下载对应的 PNG 布局参考。所有六种素材共享主题与配色；需要跨图角色一致时，可选入同一张角色参考图。

- 背景与封面：等比裁切到 1920×1080 / 960×540，避免拉伸。
- 游戏边框：等比放入 1920×1080；清空上方750像素和四个控制台内容区，保留边缘装饰。
- 角色三态图：按三个横排单元分别去除透明空白，以共同缩放比例和基线排成 1536×512。
- 边框与角色须有真实透明通道，伪透明、空图、缺失状态和损坏 PNG 会报错。输出通过安装风格包使用的同一套格式校验。

可选生成尺寸取决于服务商模型。兼容尺寸为1536×1024；支持自定义尺寸的模型可选1536×864用于背景／边框、1536×512用于角色。处理器支持8位 RGB / RGBA、非隔行 PNG，输入最长边4096、单图不超过16MB；输出单图不超过8MB，风格包不超过32MB。

尺寸和透明区域可以自动处理，角色身份、动作质量与布局是否美观仍需预览确认。更换某项的手动上传文件会替代该项已采用的生成素材；失败或取消不会清空已采用素材。

接口实现参考：[OpenAI Image generation guide](https://developers.openai.com/api/docs/guides/image-generation)。自动测试使用本机模拟图片服务验证协议与安装流程，不消耗实际服务商额度。
